An underwater digging game where the interface is part of the world and every discovery makes the central hub feel more alive.

SOLO PROJECT6 MONTHSUNREAL ENGINEUI ONLY GAME

A LIVING INTERFACE

The menu is the world.

Dungeon Diver was developed as my fifth semester project. I wanted to build a UI only game without making the experience feel like a collection of conventional menus.

The central underwater hub acts as the main interface. Navigation is embedded directly into the environment, and discoveries made while digging return to the hub as fish, plants and other life.

WORLD AS NAVIGATION

Buttons that belong to the environment.

Instead of placing a standard navigation bar over the scene, each action is represented by an object inside the hub.

CaveDungeon
ChestShop
Musical ShellSettings
Fishing HookQuit

DIG. DISCOVER. UPGRADE.

A simple loop with visible progress.

The shovel itself becomes the mouse cursor. Players dig through dungeon grids, earn currency, discover fish and plants, and improve the shovel in the shop to progress through new levels.

INTERACTION STATES

Feedback at the cursor.

Because the shovel is both tool and cursor, its visual states help communicate interaction directly where the player is already looking.
